## 1. Surface Web

The **surface web** is the portion of the internet accessible to the general public through standard search engines (Google, Bing) and regular browsers.
- Public websites
- Content indexed by search engines
- Roughly 4-5% of total internet content

---
## 2. Deep Web

The **deep web** refers to content that is not indexed by search engines but is still legitimate and accessible with proper credentials or direct URLs.
- Email inboxes
- Paywall
- Internal corporate networks / databases
- Legal records

---

## 3. The Dark Web 

The dark web is a small subset of the deep web that requires special software (e.g., Tor Browser) to access and uses overlay networks that anonymize traffic.
- Deliberately hidden, encrypted and anonymized
- Hosts both legitimate privacy-focused sites and illegal marketplaces
- Not indexed by standard search engines.
- Requires special configurations (.onion).

---
## 4. Anonymous Browsing Concepts

Online anonymity is layered; **no single tool** can provide complete anonymity.

| Tool             | What it Does                                                        | Limitations                                                             |
| ---------------- | ------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| VPN              | Encrypts traffic, hides IP from sites; shifts trust to VPN provider | Provider can log; doesn't prevent browser fingerprinting                |
| Tor              | Routes traffic through 3+ relays; strong anonymity                  | Slow; exit nodes can be malicious; not all traffic encrypted end-to-end |
| Incognito mode   | Doesn't save local history/cookies                                  | Does NOT hide you from ISPs, employers or websites                      |
| Privacy Browsers | Block Trackers, fingerprinting                                      | Still reveals IP unless combined with VPN/TOR                           |

---
## 5. Online Privacy Awareness

Privacy is about controlling what data is collected and how it is used.
1. Common data collection and vectors:
	- cookies and trackers
	- Browser fingerprinting
	- Social media profiling
	- ISP logging (browsing history)
	
2. Practical privacy hygiene
	- Audit permissions: review app/browser extension access
	- use tracker blockers
	- Compartmentalize: Use separate browsers/profiles for different activities.
	- Minimize data sharing: Limit social media oversharing and use aliases/email masking.
	- Read privacy policies
	- Keep software updated
