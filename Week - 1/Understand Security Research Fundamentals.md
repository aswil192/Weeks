## 1. Security Blogs

**Security blogs** are websites or online publications dedicated to topics in information security and cybersecurity. They cover a wide range of subjects, such as:

>- Threat intelligence: new malware, ransomware campaigns, and APTs (advanced persistent threats)
>- Incident analysis: postmortems and technical breakdowns of real-world breaches
>- Research: reverse engineering, exploit development and vulnerability research
>- GRC: governance, risk management and compliance
>- Tutorials & Tooling: penetration testing techniques, detection engineering and open source security tools

---

## 2. CVE Databases

**CVE databases** are structured, searchable repositories that catalog CVEs (Common Vulnerabilities and Exposures).
Each vulnerability has a unique ID, a description, and references.

#### Key characteristics
- Unique Identifier - One CVE ID per vulnerability
- Description - What the vulnerability is and which product/version is affected
- References: links to advisories, patches, and reports.

---

## 3. Security Advisories

**Security Advisories** are official notifications published by software vendors, security researchers or organisations warning about security vulnerabilities, threats or incidents that could affect users. They provide essential information to help organizations and individuals protect their systems.

- Vulnerability description
- Severity rating: often using CVSS (Common Vulnerability Scoring System).
- Impact: what an attacker could do, such as achieve remote code execution (RCE).
- Affected products/versions.
- Remediation guidance: patches, workarounds, or mitigation steps.
- CVE identifier: a unique reference ID, such as CVE-2024-32728.

---

## 4. Responsible Disclosure

**Responsible disclosure**, or coordinated disclosure, is a security practice in which a researcher who discovers a vulnerability privately reports it to the affected vendor and gives them a reasonable amount of time to fix it before the details are made public.

It can be difficult for researchers to know how to report issues in an organization's applications and infrastructure safely and efficiently. Creating a responsible disclosure policy can be confusing and time-consuming, so many organizations do not create one.

Many organizations implement vulnerability disclosure programs to address this by providing a dedicated platform that simplifies the reporting process and makes it easier for researchers to submit their findings.
