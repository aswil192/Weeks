## 1. Security Blogs

**Security Blogs** are Websites or online publications dedicated to topics in Information security /  cybersecurity. They cover a wide range of subjects such as 

>- Threat intelligence: new malware, ransomware campaigns, APT (advanced persistent threat)
>- Incident analysis: post-mortems and technical breakdowns of real-world breaches 
>- Research: reverse engineering, exploit development and vulnerability research
>- GRC: governance, risk management and compliance
>- Tutorials & Tooling: penetration testing techniques, detection engineering and open source security tools

---

## 2. CVE Databases

**CVE Databases** is a structured, searchable repository that catalogs CVE (Common Vulnerabilities and Exposures). 
Each vulnerability have a unique ID, a description and references.

#### Key characteristics
- Unique Identifier - One CVE ID per vulnerability
- Description - What the vulnerability is and which product/version is affected
- references - links to advisories, patches and reports.

---

## 3. Security Advisories

**Security Advisories** are official notifications published by software vendors, security researchers or organisations warning about security vulnerabilities, threats or incidents that could affect users. They provide essential information to help organizations and individuals protect their systems.

- Vulnerability description
- Severity rating - often using CVSS (common vulnerability scoring system)
- Impact - what an attacker could do?, like RCE.....
- Affected products/version
- Remediation guidance - patches, workarounds or mitigation steps
- CVE identifier - a unique reference ID, like CVE 2024-32728

---

## 4. Responsible Disclosure

**Responsible Disclosure** or coordinated disclosure is a security practice where a researcher who discovers a vulnerability privately reports it to the affected vendor and gives them reasonable time to fix it before the details are made public. 

It can be messy process for hackers to know exactly how to share in your applications and infrastructure in a safe and efficient manner. Generating a responsible disclosure policy can be confusing and time-consuming, so many organizations do not create one at all.

Many organizations choose to implement vulnerability disclosure programs to help with this by having a dedicated platform to simplify the reporting process, it makes easier for hackers to submit their findings.
